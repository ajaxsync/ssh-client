核心功能

从加密存储到文件传输，一切你需要的远程管理能力

加密主机库

主密码保护，所有主机信息本地加密存储。支持 Windows 凭据保护实现本机免密进入。

多标签连接

每条标签对应一条独立 SSH 连接。同一主机可开多条连接，标签颜色与备注一目了然。

终端 / SFTP / 监控

每条连接内自由切换终端、文件管理、系统监控。切换视图不断开连接，高效流畅。

命令片段

保存常用命令，一键插入当前终端。支持分类管理与搜索，告别重复输入。

拖拽上传

SFTP 视图支持拖拽文件直接上传到当前目录，操作直觉，传输高效。

ProxyJump 跳板机

通过跳板机安全访问内网服务器，连接前自动预检可达性与私钥。

自动重连

可配置 Keepalive 心跳与断线自动重连，网络波动不再打断工作流。

深 / 浅玻璃主题

精心打磨的玻璃拟态界面，深色与浅色双主题自由切换，视觉舒适不打折扣。

快速开始

四步即可开始你的远程连接之旅

1

下载安装

从 GitHub Releases 下载安装包，双击运行即可完成安装。

2

设置主密码

首次启动设置主密码（至少 6 位），或开启本机自动解锁。数据加密存储在本地。

3

添加主机

点击 + 号添加主机，或从 ~/.ssh/config 与 CSV 批量导入。

4

开始连接

点击主机卡片建立 SSH 连接，自由切换终端、SFTP 与监控视图。

常见问题

你可能想知道的

开发版与安装版共用 %APPDATA%\ssh-client 目录。换一台干净电脑安装即为空库。

关闭应用后删除 %APPDATA%\ssh-client，或在解锁页重置保险库。

主密码无法找回，只能在解锁页重置保险库（会删除全部主机与设置）。

从 GitHub Releases 下载新安装包，直接覆盖安装即可。本机数据保存在 %APPDATA%\ssh-client，不会被安装程序清除。

当前版本仅面向 Windows 平台。未来可能扩展到 macOS 与 Linux。

所有主机信息（含密码）经主密码加密后存储在本地。私钥仅保存文件路径，内容不会写入保险库。
